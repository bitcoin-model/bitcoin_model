🚀 如何開始
───────────────────────────────────────────────────────────────

步驟 1: 安裝 Node.js
   → https://nodejs.org/ 下載 LTS 版本

步驟 2: 安裝依賴
   方法 A: 雙擊 INSTALL.bat
   方法 B: 執行 npm install

步驟 3: 啟動開發伺服器
   方法 A: 雙擊 START.bat
   方法 B: 執行 npm run dev

步驟 4: 開啟瀏覽器
   → http://localhost:3000/zh-TW
