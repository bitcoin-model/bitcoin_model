## 🚀 如何使用

### 1. 安裝 Node.js
```
下載: https://nodejs.org/
版本: v20.x LTS
```

### 2. 安裝依賴
```bash
cd bitcoin24-spa
npm install
```

### 3. 啟動應用
```bash
npm run dev
```

### 4. 開啟瀏覽器
```
訪問: http://localhost:3000/zh-TW
```

### 5. 開始使用
```
1. 瀏覽 Intro 頁面
2. 設定 BTC 假設
3. 設定 Macro 假設
4. 選擇投資者類型
5. 執行計算
6. 查看結果
7. 匯出資料
```
