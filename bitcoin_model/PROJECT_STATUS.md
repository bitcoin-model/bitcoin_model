## 🎯 使用指南

### 快速開始

1. **安裝依賴**
   ```bash
   cd bitcoin24-spa
   npm install
   ```

2. **啟動開發伺服器**
   ```bash
   npm run dev
   ```

3. **訪問應用程式**
   - 繁體中文: http://localhost:3000/zh-TW
   - English: http://localhost:3000/en

4. **開始使用**
   - 瀏覽 Intro 頁面了解專案
   - 訪問 BTC/Macro 設定假設
   - 訪問 Individual 執行第一次計算
   - 體驗完整的投資模擬流程
