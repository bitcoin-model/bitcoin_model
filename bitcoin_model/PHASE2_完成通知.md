## 🚀 下一步：如何啟動專案

### ⚠️ 前置條件：安裝 Node.js

**在開始之前，您需要先安裝 Node.js：**

1. 訪問：https://nodejs.org/
2. 下載 **LTS 版本**（推薦 v20.x）
3. 執行安裝程式
4. **重新啟動電腦**

驗證安裝：
```bash
node --version
# 應該顯示: v20.x.x
```

---

### 📦 安裝專案依賴

進入專案目錄：
```bash
cd bitcoin_model/bitcoin24-spa
```

**方法 A：使用自動化腳本（推薦）**
```
雙擊 INSTALL.bat
```

**方法 B：手動安裝**
```bash
npm install
```

---

### 🖥️ 啟動開發伺服器

**方法 A：使用自動化腳本（推薦）**
```
雙擊 START.bat
```

**方法 B：手動啟動**
```bash
npm run dev
```
